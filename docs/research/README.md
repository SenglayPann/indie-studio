# Source research

These files are the background research the plugin was designed from. They were generated with
NotebookLM from public web sources. They are **reference material only**: the plugin does not read them
at runtime, and they are not covered by the repository license.

Treat specific facts in them (engine versions, model names, plugin versions, prices) as unverified.
The plugin's `research` skill exists precisely so those facts get checked against current sources.

| File | What it covers |
|---|---|
| Game Development Phases and Common Pitfalls for Beginners.md | Lifecycle phases, milestones, and beginner anti-patterns |
| Mobile Game Development Guide for Beginner Indie Developers.md | Engine comparison and mobile performance |
| AI Tool and Agent Workspace Setup for Mobile Game Development.md | AI agent toolchain, MCP, context files |
| how many Functional roles will a solo indie game.md | The ten roles a solo developer covers |
| NotebookLM Mind Map.png | Mind map summarizing the lifecycle and risks |
