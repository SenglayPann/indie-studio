# Plugin feedback

Notes about the `indie-studio` plugin itself: where it was wrong, in the way, or missing something.
Written as it happens by `indie-studio:plugin-feedback`, and shared only when you approve the exact text.

The game's own bugs go in `studio/BUGS.md`. Problems with Claude Code itself go to its `/bug` command.
